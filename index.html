Building the “Invite People” Box From Scratch

In tools like Gmail, Slack, and Miro, typed or pasted email addresses snap into neat, removable chips. For Miro’s April 2020 frontend assessment, I built that widget in 315 lines of plain JavaScript and CSS—no frameworks, no outside libraries. Miro asked for a reusable email-input widget—​like their own “Share board” dialog

Any product team needed to drop the widget onto a webpage, run several independent boxes side by side, and wire them up to their own buttons and forms. To make typing, line-wrapping, and pasting feel natural, I built the whole field as one continuous text surface where finished email chips sit right beside the letters you are still typing.

Without a framework, every browser quirk had to be handled by hand: keeping the blinking cursor in place as new chips appear, stopping Backspace from deleting finished chips, splitting pasted comma lists into valid chips and red-underlined typos, and making every detail behave in Internet Explorer 11.

The finished library came to 315 lines of JavaScript, 70 lines of CSS, and an automated test suite that runs live in the browser below. I passed this coding round at Miro, though the role ultimately did not pan out for other reasons.

How It Works Under the Hood

How 315 Lines Handle the Cursor, the DOM, and IE11

A chip input looks simple until you build one directly on contentEditable. Below is the DOM tree inside .emails-input, followed by fifteen implementation notes covering cursor placement, event handling, API design, and browser testing.

DOM Subtree Topology

Hybrid Editable Tree Inside .emails-input

div.emails-input [contentEditable="true"]
├── span.valid-email [contentEditable="false"]
│   ├── #text "john@miro.com"
│   └── span.delete-item ("x")
├── span.invalid-email [contentEditable="false"]
│   ├── #text "malformed-token"
│   └── span.delete-item ("x")
└── #text "" ← Caret & Placeholder Anchor
  • State vs. DOM Parity: Intercepts Backspace at anchorOffset === 0 and off-node focus so native contentEditable editing never deletes chips behind this._emails.
  • Persistent Caret Anchor: Appends an explicit trailing document.createTextNode('') after each chip so Range.setStart(lastText, 0) always lands cleanly across Chrome, Firefox, Safari, and IE11.
  • O(1) Event Delegation: Attaches bubbling focusin/focusout and a single root click listener regardless of how many email chips sit in the box.
  • Parser-Boundary XSS Safety: Zero innerHTML calls across all 315 lines; every node is built strictly with createElement, innerText, and createTextNode.

A. Keeping the Cursor, DOM, and Styles in Sync

Cards 01–08 · Browser Internals
01 · Rich-Text Editing Engine

Blocking Native contentEditable Backspace Desync

Inside a contentEditable="true" host, pressing Backspace when the caret sits at offset 0 of the trailing text node (anchorOffset === 0)—or when selection focus drifts onto a sibling node (focusNode !== lastTextNode)—causes the browser’s rich-text editor to delete the preceding contentEditable="false" chip straight out of the DOM without updating this._emails. Blocking both cases in onKeyDown keeps the DOM and state in lockstep. 

if (event.keyCode === BACKSPACE) {
  var sel = getSelection();
  var lastText = getLastTextNode(event.target);
  if (sel.focusNode !== lastText) {
    event.preventDefault();
    return;
  }
  if (sel.anchorOffset === 0) {
    event.preventDefault();
  }
}
02 · W3C Selection & Range Geometry

Seeding a Persistent CharacterData Caret Anchor

When a contentEditable="true" element holds only contentEditable="false" child <span> nodes and no trailing Node.TEXT_NODE, browsers have nowhere valid to place a collapsed cursor—causing vanished cursors in Firefox and IE11 or stray <div><br></div> wrappers in Chrome. Appending document.createTextNode('') after creating a chip gives range.setStart(lastText, 0) a reliable landing spot. 

deleteAllDirectTextNodes(containerElement);
var textNode = document.createTextNode('');
containerElement.appendChild(textNode);
/* ... on container click: */
var range = document.createRange();
range.setStart(lastText, 0);
range.collapse(true);
sel.removeAllRanges();
sel.addRange(range);
03 · DOM Tree Traversal

Reading Only Fresh Keystrokes via Direct Node.TEXT_NODE Leaves

Because the box mixes finished chip elements with live text, reading container.textContent or container.innerText sweeps up every existing email address and its x button too. getDirectTextContent() walks direct childNodes and reads only nodeType === Node.TEXT_NODE (3), isolating the letters the user just typed. 

function getDirectTextContent (el) {
  var text = '', nodes = el.childNodes;
  for (var i = 0; i < nodes.length; i++) {
    if (nodes[i].nodeType === Node.TEXT_NODE) {
      text += nodes[i].textContent;
    }
  }
  return text;
}
04 · Cursor-Preserving Mutation

Inserting Each New Chip Ahead of the Live Cursor

Inside addEmail, getLastTextNode() scans childNodes backward from the end of the container to find the active trailing text node, then inserts the new chip right in front of it with insertBefore(node, lastTextNode). Each chip snaps neatly to the left while the typing cursor stays parked at the end. 

function getLastTextNode (el) {
  for (var i = el.childNodes.length - 1; i >= 0; i--) {
    if (el.childNodes[i].nodeType === Node.TEXT_NODE) {
      return el.childNodes[i];
    }
  }
}
var lastText = getLastTextNode(_componentRoot);
_componentRoot.insertBefore(node, lastText);
05 · CSS Render-Tree Inheritance

Styling Bare Text Nodes Through Parent Color Inheritance

HTML contentEditable divs have no native placeholder attribute, and a bare DOM Node.TEXT_NODE (this._placeholderElement) cannot take a CSS class or inline style—it inherits color from its parent element. Setting .emails-input { color: #C3C2CF } paints the unfocused placeholder gray while chips override to #050038, and adding .focus { color: #000 } on focusin turns live typing black. 

.emails-input {
  color: #C3C2CF;
  &.focus { color: #000; }
  .email-input-valid-email { color: #050038; }
}

Bubbling focusin / focusout & Single-Listener Click Delegation

bindEvents attaches five listeners once on the container root: bubbling focusin and focusout handlers, paste and keydown handlers, and one delegated click handler. Inside onClick, event.target routes clicks on .delete-item to chip removal while event.currentTarget places the cursor at the end of the field—keeping listener count O(1) whether the box holds two chips or two hundred.

Bridging IE11 (Trident) and Standard Clipboard APIs

Supporting IE11 alongside modern browsers without polyfills meant handling both clipboard APIs directly: reading IE’s global window.clipboardData.getData('text') when present and falling back to standard event.clipboardData.getData('text') for comma-separated pastes, paired with plain ES5 option handling in the constructor.

08 · Parser-Boundary Security

Zero innerHTML Calls Across All 315 Lines

Invalid entries stay visible inline so people can spot and delete typos after pasting a long list. Across the entire file, innerHTML is never called once—every valid chip, typo entry, delete button, and placeholder node is built with document.createElement, .innerText, and document.createTextNode, so pasted HTML or script strings are rendered strictly as harmless text.

B. Public API Design, State Safety & Browser Tests

Cards 09–15 · Library Design
09 · Encapsulation Pattern

Private Helpers Inside an IIFE Closure + EmailsInput.prototype

All internal DOM helpers and event handlers (_addTextContentAsAnItem, _notifyListeners, bindEvents, deleteItem) stay private inside the outer IIFE closure and receive instance context via .call(this) and .bind(this), exposing only the five documented methods on EmailsInput.prototype. 

function bindEvents (elements) {
  var el = elements.container;
  el.addEventListener('paste', onPaste.bind(this));
  el.addEventListener('keydown', onKeyDown.bind(this));
  el.addEventListener('focusout', onLoseFocus.bind(this));
  el.addEventListener('focusin', onGainFocus.bind(this));
  el.addEventListener('click', onClick.bind(this));
}
10 · DOM Object Identity

Deleting Chips by Exact HTMLElement Reference

Each item in this._emails stores both the string and a direct reference to its mounted DOM node. When someone clicks x, deleteItem(node) compares exact HTMLElement references (current.node === node), so even if the same address appears twice, clicking x removes the exact chip clicked without scraping text from the DOM. 

for (var iter = 0; iter < this._emails.length; iter++) {
  var current = this._emails[iter];
  if (current.node === node) {
    correspondingItem = current;
  }
}
11 · DOM Wrapper Guard

Preventing Double-Mounting Without Extra HTML Attributes

On setup, the constructor stores hostElement['x-emails-input'] = this on the JavaScript HTMLElement object itself—leaving the page’s HTML attributes untouched while throwing a clear error if caller code tries to mount a second widget onto the same element. Likewise, setEmails() checks emailsList instanceof Array right at the door. 

var prop = 'x-emails-input';
if (typeof hostElement[prop] !== 'undefined') {
  throw Error('Already instantiated on this element.');
}
this._hostElement[prop] = this;
12 · State Immutability & Idempotency

Fresh Array Copies & Deduplicated Change Listeners

getEmails(), getAllItems(), and _notifyListeners() always return fresh arrays via .map() so outside callers cannot mutate internal state—verified in Chai via expect(currentListOfEmails).to.not.equal(emails). And addChangeListener checks indexOf(listener) === -1 so registering the same callback twice only fires it once. 

EmailsInput.prototype.addChangeListener = function (fn) {
  if (this._changeListeners.indexOf(fn) === -1) {
    this._changeListeners.push(fn);
  }
};
13 · Visual Spacing & Dual Getters

Wider Margins Between Dashed Typos (7px vs. 3px)

Valid emails sit inside a filled blue pill needing only a 3px gap, while typos sit on a transparent background with a 1px dashed #f00 underline. Giving siblings after an invalid entry a 7px left margin keeps two red dashed underlines from running together into one long line, paired with separate getEmails() and getAllItems() readers. 

.email-input-invalid-email + .email-input-invalid-email {
  margin-left: 7px;
}
.email-input-valid-email + .email-input-valid-email {
  margin-left: 3px;
}

15 · Looking Back Six Years Later

Three Small Edge Cases I Spotted Re-Reading the 2020 Code

Reading my April 2020 submission verbatim today—while keeping the original source files untouched—three small edge cases stand out that I would tighten now: (1) setEmails() removes existing chip nodes from the DOM and should also reset this._emails = [] before adding the new list; (2) deleteAllDirectTextNodes loops forward over a live childNodes list rather than backward like getLastTextNode; and (3) clicking .delete-item removes the chip cleanly and should also call _notifyListeners.call(this). 

/* 1. Reset state in setEmails() */
this._emails = [];
/* 2. Walk live childNodes backward */
for (var i = el.childNodes.length - 1; i >= 0; i--) {
  if (el.childNodes[i].nodeType === Node.TEXT_NODE) {
    el.removeChild(el.childNodes[i]);
  }
}
/* 3. Fire listeners in deleteItem() */
_notifyListeners.call(this);

var EmailsInput = (function () {

    var emailValidationRegex = /^(([^<>()[\]\\.,;:\s@\"]+(\.[^<>()[\]\\.,;:\s@\"]+)*)|(\".+\"))@((\[[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\])|(([a-zA-Z\-0-9]+\.)+[a-zA-Z]{2,}))$/;

    function isValidEmail (possibleEmail) {
      return emailValidationRegex.test(possibleEmail);
    }

    function createElement (tagName, attributes) {
      var element = document.createElement(tagName);
      for (var attribute in attributes) {
        element.setAttribute(attribute, attributes[attribute]);
      }
      return element;
    }

    var defaultOptions = {
      placeholder: 'add more people...'
    };

    function getDirectTextContent (element) {
      var text = '';

      for (var iter = 0; iter < element.childNodes.length; iter++) {
        var childNode = element.childNodes[iter];
        if (childNode.nodeType === Node.TEXT_NODE) {
          text += childNode.textContent;
        }
      }
      return text;
    }


    function deleteAllDirectTextNodes (element) {
      for (var iter = 0; iter < element.childNodes.length; iter++) {
        var childNode = element.childNodes[iter];
        if (childNode.nodeType === Node.TEXT_NODE) {
          childNode.parentNode.removeChild(childNode);
        }
      }
    }

    function _addTextContentAsAnItem (containerElement) {
      var content = getDirectTextContent(containerElement);
      this.addEmail(content);
      deleteAllDirectTextNodes(containerElement);
      var textNode = document.createTextNode('');
      containerElement.appendChild(textNode);
    }

    function onKeyDown (event) {
      var RETURN_KEYCODE = 13;
      var COMMA_KEYCODE = 188;
      var BACKSPACE = 8;
      if (event.keyCode === RETURN_KEYCODE || event.keyCode === COMMA_KEYCODE) {
        event.preventDefault();
        _addTextContentAsAnItem.call(this, event.target);
        return;
      }

      if (event.keyCode === BACKSPACE) {
        var currentSelection = getSelection();
        var lastTextNode = getLastTextNode(event.target);
        if (currentSelection.focusNode !== lastTextNode) {
          event.preventDefault();
          return;
        }

        if (currentSelection.anchorOffset === 0) {
          event.preventDefault();
        }
      }

    }

    function onPaste (event) {
      event.preventDefault();
      var self = this,
        pasteContent;
      if (!!window.clipboardData) {
        pasteContent = window.clipboardData.getData('text');
      } else {
        pasteContent = event.clipboardData.getData('text');
      }
      var emails = pasteContent.split(',');
      emails.forEach(function (email) {
        self.addEmail(email);
      });
    }

    function deleteItem (node) {

      var correspondingItem;
      for (var iter = 0; iter < this._emails.length; iter++) {
        var current = this._emails[iter];
        if (current.node === node) {
          correspondingItem = current;
        }
      }

      var index = this._emails.indexOf(correspondingItem);

      this._emails.splice(index, 1);
      node.parentNode.removeChild(node);
    }

    function onClick (event) {

      if (event.target.classList.contains('delete-item')) {
        deleteItem.call(this, event.target.parentNode);
        return;
      }
      var componentRoot = event.currentTarget;
      var range = document.createRange();
      var sel = window.getSelection();
      var lastText = getLastTextNode(componentRoot);
      if (typeof lastText === 'undefined') {
        return;
      }
      range.setStart(lastText, 0);
      range.collapse(true);
      sel.removeAllRanges();
      sel.addRange(range);
      event.preventDefault();
    }

    function onLoseFocus (event) {
      var _componentRoot = event.target;
      _addTextContentAsAnItem.call(this, _componentRoot);
      this._placeholderElement = document.createTextNode(this._placeholderText);
      _componentRoot.appendChild(this._placeholderElement);
      _componentRoot.classList.remove('focus');
    }

    function bindEvents (elements) {
      var container = elements.container;
      container.addEventListener('paste', onPaste.bind(this));
      container.addEventListener('keydown', onKeyDown.bind(this));
      container.addEventListener('focusout', onLoseFocus.bind(this));
      container.addEventListener('focusin', onGainFocus.bind(this));
      container.addEventListener('click', onClick.bind(this));
    }

    function onGainFocus (event) {
      if (this._placeholderElement.parentNode !== null) {
        this._placeholderElement.parentNode.removeChild(this._placeholderElement);
      }
      event.target.classList.add('focus');
    }

    function createValidEmailNode (email) {
      var emailAddressElement = createElement('span', {
        'class': 'email-input-valid-email',
        'contentEditable': 'false'
      });
      emailAddressElement.innerText = email;

      var deleteElement = createElement('span', {
        'class': 'delete-item'
      });
      deleteElement.innerText = 'x';
      emailAddressElement.appendChild(deleteElement);
      return emailAddressElement;
    }

    function createInvalidEmailNode (content) {
      var invalidEmailItem = createElement('span', {
        'class': 'email-input-invalid-email',
        'contentEditable': 'false'
      });
      invalidEmailItem.innerText = content;
      var deleteElement = createElement('span', {
        'class': 'delete-item'
      });
      deleteElement.innerText = 'x';
      invalidEmailItem.appendChild(deleteElement);
      return invalidEmailItem;
    }


    function _notifyListeners () {
      var self = this;
      this._changeListeners.forEach(function (listener) {
        var emailsListCurrent = self._emails.map(function (item) {
          return item.email;
        });
        listener(emailsListCurrent);
      });
    }

    function getLastTextNode (element) {
      var lastTextNode;
      for (var iter = element.childNodes.length - 1; iter >= 0; iter--) {
        var currentNode = element.childNodes[iter];
        if (currentNode.nodeType === Node.TEXT_NODE) {
          lastTextNode = currentNode;
          break;
        }
      }
      return lastTextNode;
    }

    function EmailsInput (hostElement, providedOptions) {

      // var options = Object.assign({}, defaultOptions, providedOptions)
      var options = {};
      if (typeof providedOptions !== 'undefined') {
        options.placeholder = providedOptions.placeholder;
      } else {
        options.placeholder = defaultOptions.placeholder;
      }

      this.hostElement = hostElement;
      this._emails = []; //list of email addresses
      this._hostElement = hostElement;
      this._placeholderText = options.placeholder;
      this._placeholderElement = document.createTextNode(this._placeholderText);


      this._changeListeners = [];
      var elementAttributeProperty = 'x-emails-input';
      if (typeof hostElement[elementAttributeProperty] !== 'undefined') {
        throw Error('Attempting to instantiate another instance of emails input on a element with a emails input already instantiated.');

      }
      this._hostElement[elementAttributeProperty] = this;
      var container = createElement('div', {
        'class': 'emails-input',
        'contentEditable': 'true'
      });
      this._hostElement.appendChild(container);

      this._componentRoot = container;
      bindEvents.call(this, {
        container: container
      });
      this._componentRoot.appendChild(this._placeholderElement);
    }

    EmailsInput.prototype.setEmails = function (emailsList) {
      if (!(emailsList instanceof Array)) {
        throw new Error('setEmails() given a non Array argument.');
      }

      this._emails.forEach(function (item) {
        item.node.parentNode.removeChild(item.node);
      });

      deleteAllDirectTextNodes(this._componentRoot);

      for (var iter = 0; iter < emailsList.length; iter++) {
        this.addEmail(emailsList[iter]);
      }
      _notifyListeners.call(this);
    };

    EmailsInput.prototype.getEmails = function () {
      var validItems = this._emails.filter(function (item) {
        return item.isValid === true;
      });

      return validItems.map(function (item) {
        return item.email;
      });
    };

    EmailsInput.prototype.getAllItems = function () {
      return this._emails.map(function (item) {
        return item.email;
      });
    };

    EmailsInput.prototype.addEmail = function (email) {

      if (email.trim().length === 0) {
        return;
      }

      email = email.trim();

      var item = {
        email: email,
        node: null,
        isValid: false
      };
      var node = null;
      if (isValidEmail(email)) {
        node = createValidEmailNode(email);
        item.email = email;
        item.node = node;
        item.isValid = true;
      } else {
        node = createInvalidEmailNode(email);
        item.email = email;
        item.node = node;
        item.isValid = false;
      }
      this._emails.push(item);

      //add the new email address before the current node where the cursor is
      var _componentRoot = this._componentRoot;
      var lastTextNode = getLastTextNode(_componentRoot);
      this._componentRoot.insertBefore(node, lastTextNode);
      _notifyListeners.call(this);
    };

    EmailsInput.prototype.addChangeListener = function (listener) {
      if (this._changeListeners.indexOf(listener) === -1) {
        this._changeListeners.push(listener);
      }
    };

    return EmailsInput;
  }
)();
